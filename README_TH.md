# SMART FARM — ADVANCED INVESTIGATION 2.0

แอปเกมสืบสวนเทคโนโลยีแบบแยกเดี่ยว สำหรับ ม.4 หน่วย ระบบทางเทคโนโลยี หัวข้อ **ความสัมพันธ์ของเทคโนโลยีกับศาสตร์อื่น**

## วิธีเปิดเล่น

1. แตกไฟล์ ZIP
2. ในโฟลเดอร์โปรเจกต์ เปิด Terminal แล้วรัน `python -m http.server 8000`
3. เปิด `http://localhost:8000/` ในเบราว์เซอร์ (ไม่เปิด `index.html` ตรง ๆ ผ่าน file:// เพราะ ES Modules อาจถูกบล็อก)

**ไม่ต้องติดตั้ง npm และไม่มี dependency ภายนอกสำหรับเกม** (ฟอนต์ Google มีแบบสำรองหากออฟไลน์)

## วิธีเผยแพร่ GitHub Pages

สร้าง Repository **ใหม่แยกต่างหาก** เช่น `SMART_FARM_ADVANCED_2_0` และอัปโหลดไฟล์ทั้งหมดที่ root ของ Repository รวมโฟลเดอร์ `.github/workflows/` จากนั้นตั้ง Pages → Source → GitHub Actions แล้วตรวจ Workflow `Deploy SMART FARM 2.0` หากเป็นสีเขียวจึงเปิดลิงก์ `https://<username>.github.io/<repo>/` โครงการนี้ใช้ path แบบสัมพัทธ์ ไม่ต้อง Build ผ่าน Vite

## โครงสร้าง

- `index.html` — หน้าเริ่มต้น
- `src/styles.css` — Design System, HUD, Layout, Responsive
- `src/data.js` — หลักฐาน 5 ชิ้น, ศาสตร์ 5 ด้าน, 3 ภารกิจซ่อม, 10 คำถาม และ Worksheet Contract
- `src/engine.js` — การคำนวณผลจำลอง, การปลดล็อก, คะแนน, การบันทึกความก้าวหน้า, การส่งออก
- `src/app.js` — UI และการโต้ตอบ
- `tests/engine.test.mjs` — automated tests
- `.github/workflows/deploy.yml` — GitHub Pages workflow สำหรับ Static Files

## เนื้อหาและหลักการ

วิทยาศาสตร์, คณิตศาสตร์, วิศวกรรมศาสตร์, ศิลปะและการออกแบบ, สังคมศาสตร์ เน้นการเชื่อมโยงศาสตร์กับหลักฐานของระบบรดน้ำอัตโนมัติ ไม่ใช่แบบทดสอบความจำอย่างเดียว

## ข้อจำกัดที่ต้องทราบ

- ฉากสำรวจใช้ **ภาพ Isometric แบบ 2.5D พร้อมมุมมองหมุนจำลอง** ไม่ใช่โมเดล WebGL 3D จริง
- แบบจำลองน้ำใช้สมมติฐานอัตราการไหลคงที่ ไม่ใช่การออกแบบระบบชลประทานเชิงวิศวกรรม
- NOVA เป็นผู้ช่วยตามสคริปต์ ไม่ใช่บริการ AI ภายนอก
- ข้อมูลเก็บ Local Storage ในเครื่อง ไม่ส่งคะแนนรวมทั้งห้อง
- ทุกหลักฐาน/ผลทดลอง/คำตอบมีข้อมูลประกอบสำหรับพัฒนาใบงานภายหลัง แต่ **ยังไม่จัดทำใบงาน** ตามคำขอ
